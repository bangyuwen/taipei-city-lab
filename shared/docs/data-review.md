## 樹木

- 資料目錄：[臺北市行道樹及公園樹木分布圖](https://data.gov.tw/dataset/128274)。目錄已確認政府資料開放授權條款第 1 版與 JSON 下載連結。
- 實際來源：[TaipeiTree.json](https://tppkl.blob.core.windows.net/blobfs/TaipeiTree.json)。SHA-256：`cce57bfd18cd444810ff287c8369e0dcddd4660d72ba57454937e1779df7c93b`。
- 原座標欄位為 `TWD97X`、`TWD97Y`；使用 pyproj 3.8.0 與 EPSG:3826（TWD97 / TM2 zone 121）轉換為 EPSG:4326，`always_xy=True`。輸出 `x` 為經度、`y` 為緯度，保留小數點 7 位。
- 一筆已核對的轉換：`302404.92, 2777358.41` → `121.5196012, 25.1036454`。以相同投影反轉回原座標，誤差驗證小於 0.01 公尺。
- 原 `TreeID` 作為 ID；沒有重複 ID。框內轉換與四捨五入後有 3 個重複座標計數，均保留；同一位置不等於同一棵樹。
- 欄位對應：`TreeHeight` → `height`，`Diameter` → `diameter`，`TreeType` → `species`，`Dist` → `district`，`SurveyDate` → `surveyDate`，`UpdDate` → `updatedAt`。來源目錄未定義樹高／胸徑單位，因此保留來源原值，模型若使用須先確認單位及品質。

### 日期與品質

`surveyDate` 是逐樹調查日，`updatedAt` 是來源系統更新時間，`retrievedAt` 是下載時間。這三者不能互換。本次框內所有 `UpdDate` 都是 `2026-10-13 16:03:58`，但調查日最晚為 `2026-10-08`。來源時間字串沒有標示時區，原字串保留，沒有擅自補上時區。

| 框內欄位問題 | 數量 | 處理 |
|---|---:|---|
| 空白調查日 | 1 | 輸出 JSON `null`，未填入更新日 |
| 調查日 `1900-01-01` | 1 | 保留原值並列為品質警示，不作有效近期調查 |
| 樹高大於 50 | 6 | 保留原值並列為極端值；其中最大值 153.8 |
| 樹高為 0 | 14 | 保留原值，不能當有效樹冠估算依據 |
| 胸徑為 0 | 4 | 保留原值，不能當有效尺寸估算依據 |

除調查日 1 筆空值外，輸出所需欄位沒有空值。`quality.trees.nullCounts` 記錄框內各輸出欄位的空值數量。極端值警示為資料查核門檻，不是判定樹木真實高度或存活狀態。

官方資料沒有樹冠輪廓、建物遮蔭、實測熱暴露、完整移除原因或可施工樹穴。現有樹點可以支援「樹點空間密度」；任何樹冠半徑、遮蔭效益、人口權重與新增候選點都屬情境假設，需要另外揭露。

### 發現的問題

目錄 `number_of_data` 顯示 2,009；實際總表只有 681 個資料列。本版依下載檔案計數，`quality.bins.catalogCountMismatch=true`；未採用頁面筆數代表現況。

CSV 第 655 行的原始經度為 `?121.595369`，無法解析為數字，未擅自移除 `?` 或推測修正，該筆排除並記錄行號。其餘 680 筆座標有效。框內 294 筆資料無空值、重複 ID 或重複座標；全市檔案中存在相同座標紀錄，不能逕自合併為同一設施。

缺少容量、垃圾重量、滿溢時間、清運排程及人行路網，不能由位置資料直接估算實際滿溢或清運成本。直線服務距離為情境代理，不能說成步行可達距離。

## 重建與驗證

```sh
python -m pip install pyproj
python scripts/prepare-data.py --refresh
```

命令下載來源、嚴格解析 CSV、轉換座標，產生 `dist/data/snapshot.json` 與 `dist/data/source-catalog.json`。若要從既有來源快取重建，使用 `--offline --cache-dir <既有快取路徑>`。預設快取為 `/tmp/taipei-city-lab-source-cache`；快取不在公開網站內。來源每日可能更新，因此 `--refresh` 的筆數與 SHA 不一定與本次相同。

本次驗證通過：所有輸出座標有限且位於 bbox；樹與桶唯一 ID；來源列數守恆（範圍內＋範圍外＋無效座標＝原檔案列數）；來源欄位與空值保留；13 個來源 ID 齊全。JSON 使用 `allow_nan=False`，拒絕輸出 NaN 或 Infinity。Snapshot 約 7.39 MB。

Meta 的 `retrievedAt` 為所載來源最後下載時間；`builtAt` 為本次轉換建置時間。離線重建不會把舊來源日期偽裝為重新下載日期。資料準備階段使用 `buildStatus=creating`；網站整合完成後已更新為 `complete`。
