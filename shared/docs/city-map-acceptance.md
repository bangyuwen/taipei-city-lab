# 連續城市地圖驗收

使用者指出「為什麼你一直給我方的地圖」。先前重設了網站介面，卻保留研究原型的矩形底圖裁切、厚底座與格線，手機 3D 因而仍像一塊棋盤。這次修正地圖呈現，沿用已確認的城市專刊方向。

## 修改範圍

- 街道圖及四個地理題的 3D 都以實際 OpenStreetMap 街道作為連續背景。3D 不再畫厚底座、格線或四區標籤。
- 3D 依相機可見地面載入單一縮放層級、最多 24 張圖磚；平移、縮放及容器尺寸變更會更新圖磚，移出的材質、幾何與紋理會釋放，過期載入回呼不能復活舊圖磚。
- 點位與公尺半徑持續使用研究資料的固定 Web Mercator 投影，背景延伸不會擴大資料或改變方案數值。
- 2D／3D 的「模型計算範圍」為預設關閉的可選圖層；原始範圍（緯度 25.02–25.08、經度 121.51–121.57）持續列在說明。比較圖與計算中的四區仍是模擬分區。
- 垃圾桶既有／推薦點位採固定螢幕尺寸、深色圓點與白邊，選取位置保留朱橘環；啟用計算範圍會自動俯視完整範圍。3D 預設採朝北的近距離斜視；保留俯視、全域、鍵盤平移、縮放與位置聚焦。北向 SVG 隨相機旋轉，地圖上方說明有暖白底以維持可讀性。

交通、公車及健檢的 3D 是示意圖，不改稱地理路網；研究模型、原始快照與推薦座標均未修改。

## 驗證證據

- `npm test`：14 個測試檔通過。新增相機四角的圖磚覆蓋、固定投影與平移資源釋放／過期回呼檢查；保留原有座標、半徑、資料來源與全部題目檢查。
- `npm run check`：七題預設與極端條件、來源、語法及靜態資產檢查通過。
- `python scripts/check-browser.py --chromium /usr/bin/chromium`：標題導覽、鍵盤捲動、對話框焦點、圖示、窄螢幕圖表與七題地圖／3D 生命週期檢查通過；此項刻意阻擋外部圖磚。
- `.impeccable/review/city-map/results.json`：桌機 1440、手機 390／320，共 12 項檢查，0 page errors。地理四題在桌機／390px，清潔箱另加 320px，均無整頁水平溢出；切換視角保持模型數值。
- 全域視角以推薦圖層開關比較實際 canvas，桌機／390px／320px 分別有 2834／2853／2855 個改變的像素，確認點位仍有繪製。
- captures 包含街道、斜視、俯視、範圍開關、平移縮放、聚焦、全域及工作區。清潔箱預設斜視／範圍畫面重新從沒有先前選取的新文件取得；各檔 SHA-256 與受測 runtime SHA-256 一併記錄。
- 真實圖磚以 QA-only HTTPS relay 保留實際 browser User-Agent、localhost Referer 與 Accept，驗證 OS CA／TLS；沒有替換圖片、停用 TLS 或變更持久信任。

以上為本機 Chromium 154、SwiftShader 與模擬觸控裝置的驗證；不代表 Safari、Firefox、實體手機或硬體效能測試。

獨立 Impeccable 初輪完整審查確認連續地圖已回應方形底座問題，另提出點位階層／選取及手機範圍顯示兩項修正。修正後的 Verdict Pass 將兩項均評為 resolved，disposition 為 ship，範圍限於這兩項修正。完整審查、原始 manifest 與最終 verdict 保留在儲存庫的 `.impeccable/review/city-map/`；36 張最終 captures 的來源／圖片 SHA-256 全部吻合。
