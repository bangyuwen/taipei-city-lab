# 實際地圖、3D 對齊與模型界線

OpenStreetMap與Leaflet提供街道定位，Three.js呈現模型中的空間關係；兩者共用同一份座標與模型結果。

## 畫面怎麼使用

| 功能 | 操作 | 看得到的資訊 |
|---|---|---|
| 街道定位 | 平移、縮放、全域 | 真實道路、地名與地標；虛線框是示範資料範圍 |
| 圖層 | 切換既有快照、需求、候選、推薦與範圍 | 觀測點位與合成情境分開標示；需求點可顯示基準／新增覆蓋顏色 |
| 基準比較 | 切換既有基準／推薦方案 | 地圖與 3D 的方案狀態一起切換，模型參數及結果不被更動 |
| 選取連動 | 點選地圖標記、下拉選單或「3D 聚焦」 | 同一個點位 ID 在兩個畫面對應；3D 選取回到地圖並顯示座標、來源與說明 |
| 3D 底圖 | 旋轉、俯視與縮放 | 真實圖磚貼在地面，造型與半徑依相同座標定位；地形與建物仍為未載入 |
| 網路／GPU 相容 | 失敗時的狀態提示 | 街道地圖不需要 WebGL；圖磚未載入會明示，模型與匯出仍可使用 |

## 來源與解讀

- 補樹與垃圾桶：既有設施是真實觀測快照；需求、候選與推薦均為合成規劃情境。樹點顯示抽樣至 3,000 處、模型使用全部有效點位；垃圾桶 294 處全部顯示。
- 鼠患與建物：底圖是真實街道，但所有個案點位及指數仍為合成，不代表真實地址的鼠患或結構安全。圖層及選取資訊保留這個標示。
- 交通與接駁：提供內湖地理參考，未畫出虛構實際路線、流量或 OD。原時間動畫仍是合成單瓶頸／站址。
- 資料健檢沒有預設地理粒度，故不強加位置圖。
- 底圖只供辨識位置，沒有改變覆蓋模型。圓仍是公尺距離與繞行假設，不是真實步行路網等時圈；設置位置仍需現勘。
- 地圖即時圖磚與設施調查日期分別解讀，不能把街道標示的現況當成設施更新證據。

## 對齊與工程

使用標準 EPSG:3857 投影，以示範範圍的 Mercator 中心為 3D 原點。Leaflet 使用同一個投影；模型公尺圓再依中心緯度與模型／Leaflet 的地球半徑校正。座標長度映射至 Three.js X／Z，北為負 Z。

3D 圖磚依相機可見的地面範圍載入，固定的示範範圍投影、點位與模型公尺距離不隨平移縮放而改變。周邊街道只供定位，不擴大模型資料範圍；重複圖磚會重用紋理。圖磚不納入離線包或提供批次預載。2D 使用目前視窗請求，HTTP 快取採瀏覽器／服務回應的預設行為。

Leaflet 程式、CSS、圖片與除錯 source map 內附同站，固定版本及 SHA 清單；OpenStreetMap 圖磚在線載入。2D 地圖及 3D 畫面都保留可見的 OpenStreetMap contributors 來源連結。

圖磚失敗時顯示未載入狀態。離開頁面移除地圖事件與 ResizeObserver；3D 場景釋放圖磚幾何、材質與紋理。載入完成若晚於場景處置，不會重建已移除的場景。
