# 共用元件與研究規範

- `lib/`：地理、空間配置與資料契約的共用純函式。各題模型來源在 `../topics/<題目>/model.js`。
- `data/`：原保存快照的範圍與時間，以及捷運、原始市政題目等跨題來源定義。
- `docs/`：跨題研究、資料品質與介面規範；各題研究正文在各題的 `docs/`。
- [skills/](skills/README.md)：各站共用的代理技能；`.agents/` 與設計工具入口以相對連結指向維護來源。

`web/template/` 是共用呈現程式與靜態資產的維護來源；原整合站的相容產物位於 `sites/taipei-city-lab/dist/`。各獨立站由建置流程帶入需要的元件，不跨站載入程式或資料。請修改各題的模型與資料來源，再執行 `npm run build`，避免直接修改生成副本。
