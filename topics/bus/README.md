# 公車接駁與休息排程

題目 ID：`bus`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-bus-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

公車與捷運來源只查到目錄及彙總入口，未載入站點 OD、刷卡、車輛勤務或駕駛班表。到站需求與行車條件為合成單站情境。

比較車數、班距、休息及搭載／留站；單站模型不等於真實路線、轉乘或全網服務成效。

本題[資料目錄](data)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#其餘來源已查目錄未整合觀測)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-bus-lab/README.md)。
