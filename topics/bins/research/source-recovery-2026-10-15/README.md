# 2024 與 2026 清潔箱清冊補查

查詢日期：2026-10-15，Asia/Taipei。目的為找回 2024 年缺頁，以及下載目前官方對全市公開的行人專用清潔箱資料。本資料包保存歷史觀察與離線核對所需的來源，不自動刷新。

## 結果與可用檔案

| --- | ---: | ---: | --- |
| [2024 年 10 月官方 CSV 封存版](taipei-bins-2024-10-18-archive-utc.csv) | 1,971 | 12 | 已取回整份封存回應，可作另一份 2024 歷史快照；不能回填成 5 月的同日期清冊。 |

CSV 欄位均為行政區、地址、經度、緯度、備註。分享用檔案轉為 UTF-8 BOM；Big5/CP950 原始下載位元組留在 `raw/`。列序、欄序、欄值與相同座標紀錄均保留，不修正或刪除異常座標。

### 2024：找到另一份全檔，原 5 月缺頁仍未找回

原副本的匯入日期為 2024-05-14，API 回報總數 1,991，但實際只保存 offset 0、limit 1000 的 1,000 列。因此同日期仍缺 991 列。

本輪找到官方 CSV 的 Internet Archive 封存，CDX 時間為 **2024-10-18 21:17:32 UTC**，換算台北時間為 **2024-10-19 05:17:32**。檔名保留 UTC 索引日期。這是封存時間，不是設置日期、原調查日期或已知的資料更新時間。

下載的 184,116 位元組與封存索引的 SHA-1/Base32 payload digest 相符，嚴格以 CP950 解碼後有 1,971 列。這能確認取得該份封存回應，不能單獨證明當年全市現場設施都已列入。

以五個公開欄位去除首尾空白後作多重集合比較，原 5 月的 1,000 列中，只有 668 列與 10 月資料完全一致，332 列不一致或未出現在 10 月檔。這不是逐桶身分配對，也不是撤除數。**兩份資料應並存，不能拼接為 2024-05-14 的 1,991 列。**

查找範圍與結果：

- 原 `Cleaning-Box` 副本的資料檔只有一筆提交紀錄；固定版本的檔案樹沒有第二頁資料。
- 查詢 `data.taipei` 與舊 `opendata.taipei` 的已知 API 路徑，2024 年 CDX 未回傳封存；對第二頁的精確 availability 查詢也未回傳副本。
- 官方 CSV 下載路徑的 2024 CDX 找到上述 10 月封存，與下載內容雜湊相符。
- 另外檢查三個垃圾桶 App 的目前檔案樹，未找到可直接補入的 CSV/JSON 清冊。2024 年「科技人」封存頁指向的 `18787.js`，2024 CDX 無副本，封存重播回傳 404；目前原網址轉至首頁 HTML，未當成資料。

這些是有範圍的搜尋結果，不代表網路上或提供機關內部沒有其他歷史版本。

### 2026：完整下載為 681 列，與目錄筆數不一致

官方主檔標示更新時間 `2026-09-30 15:55:35`。2026-10-15 重新下載的位元組雜湊，與專案先前 provenance 記錄的來源下載雜湊相同。

同一資源 API 回報 count 681：offset 0 取得 681 列，offset 1000 與 2000 均為空。CSV 與 API 的五個公開欄位經首尾空白正規化後，多重集合完全相同。**681 不是漏抓第二頁造成的結果。**

但資料目錄的 `number_of_data` 仍為 2,009，與檔案和 API 不符；主檔北投區 0 列、南港區 4 列。現有證據不足以區分來源漏列、目錄未更新或實際配置變化，不能將北投 0 列宣告為現場沒有桶，也不能拿 2,009 減 681 當撤除量。

130 筆景點商圈清單含北投 10 個場所，但缺逐箱官方編號、場所開放時間與管理權責等欄位。不能直接加入主檔並宣稱有 811 個垃圾桶。

## 離線重跑

Python 3 標準函式庫即可，不需安裝套件或網路：

```sh
python3 research/source-recovery-2026-10-15/verify.py
```

程式核對 manifest 內 28 份來源與匯出檔的大小及 SHA-256、原始與 UTF-8 欄值和列序、封存 payload digest、API 分頁與 CSV 一致性，以及 5 月與 10 月的差異，再重建 `quality-summary.json`。此處核對的是固定快照，不是日後的來源健康檢查或全市現勘。

[manifest.json](manifest.json) 記錄版本、日期語義、轉換方式、來源檔與雜湊；[raw/requests.json](raw/requests.json) 保留公開請求網址、狀態及必要回應標頭，不保存工作階段 Cookie。主要原始檔位於 `raw/`。
