# 北投、南港行人專用清潔箱涵蓋核查

觀察日：2026-10-18（臺北時間）。官方地圖、資料平台 CSV 與 API 在當日凌晨重新取得；資料集本身標示更新日為 2026-09-30。

## 結論

官方主檔 CSV、API 首頁及環保局位置圖各有 681 筆，按行政區、地址、經緯度與備註逐欄比對後完全相符。三者都列北投區 0 筆、南港區 4 筆；本輪沒有找到可核實、目前仍設置的北投或南港新增街頭位置。這只能描述公開清冊與地圖收錄內容，不能證明北投現場沒有清潔箱。

因此將先前較肯定的「清單缺口」修正為「撤除或未收錄待釐清」：現有資料無法區分現場撤除與資料未收錄。資料平台目錄仍標示 2,009 筆，與實際 CSV、API 和地圖不符；差額不能當作撤除數或缺漏數。

## 判讀界線

- 臺北市議會 2026-08-14 質詢紀錄中，議員詢問北投行人果皮箱是否已全數撤除；環保局回覆部分商圈、夜市調整時「之前可能有整個移除」，並說明配置持續變動。紀錄沒有確認北投全數撤除，也沒有確認目前北投為零，因此仍須向主管機關釐清。
- 2024-10-18 UTC 的歷史封存檔有 1,971 列，其中北投 98、南港 94。這是不同日期的快照，不回填為目前設置數。
- 環保局另有狗便袋清潔箱資料，包含可能與既有位置重疊的紀錄及公園內子地點。設施類型、管理機關與同址關係未核實，不加入現況街頭位置。
- 先前整理的 2,663 則民眾回饋不是全市抽樣，不能推論全市人口意見；資料也沒有可核實的日期與事件位置，本核查不以此推定設點或撤除事件。

## 重現與後續查核

在網站目錄執行 `python3 scripts/package-research.py`。程式以已保留的來源位元組核對雜湊，再核對地圖、API 與主檔的位置欄位，分開彙整場域處數。既有語意摘要未重分類；[十二區交叉判讀](../feedback-distribution-2026-10-18/README.md)由同一流程產生。

優先補有日期的現存與撤除清冊、跨機關管理責任、場域開放與接收規則，再以有時間與地點的回饋核對實際路徑及桶況。沒有這些資料前，不能判定新增桶位或增加巡收哪項較有效。

## 地圖上的場域線索

2026-10-18 將上述北投 10 處、南港 5 處加入地圖獨立圖層。只有選擇「2026 官方公開主檔」才顯示；街頭紀錄用圓點，場域線索用菱形，兩者分開計數。行政區與名稱搜尋會分別篩選兩種資料，關閉場域圖層不改變街頭清冊。

圖層沿用來源座標，未重新定位。例如南港 LALAPORT 的原始經度僅 `121.6`，不能當成入口或桶位。所有場域皆標為約略位置，開放時段、接收規則、現場桶況與管理責任仍待確認。地圖空白也不是已核實的服務缺口；其他行政區的場域未納入這個圖層。

公開圖層僅包含這 15 處所需的名稱、行政區、原始座標與來源說明；完整研究附件仍不公開。既有街頭資料版本、各區列數與跨期比較保持原有口徑。重新執行 `python3 scripts/prepare-data.py` 可從保存來源產生同一圖層。
