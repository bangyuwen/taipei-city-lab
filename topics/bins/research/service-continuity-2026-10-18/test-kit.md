# 投放服務銜接主持與記錄包

適用協定：0.1　材料包：0.1.0。與 [驗證計畫](README.md) 一起使用。所有 X／Y 點位與時段皆為桌面演練資料，不供真實導航。

已備妥[材料入口](start.html)、[參與者列印卡](output/pdf/participant-cards.pdf)與[26 頁主持記錄表](output/pdf/facilitator-sheets.pdf)。入口與主持表不能交給參與者。S1、S2 的 M1 紙本各有兩頁，須同時交付，不把完整事實頁留在主持人手上。所有卡片單面列印，避免背面出現下一題；做完收回再交下一張。手機由入口開啟單張卡，頁面不保存答案。S3 的更新由主持人換卡，不由受測者預先切換情境。

## 主持開場

「我們想知道這張投放資訊能不能幫助你完成事情。今天測的是服務設計，不是考你的能力。你可以隨時停止。請照平常習慣閱讀，說出你會怎麼做；不確定時也請直接說。研究者會記錄操作與回答，不需要提供住址、固定作息或其他身分資料。」

取得同意後再開始。以匿名 P01 等代號記錄；招募聯絡資料與研究筆記分開保管。不錄影為預設；錄音、錄影或可識別照片需要另行同意。每題計時結束後才追問理由，不把提示後的回答算獨立成功。

## 研究用文字清單 M0

M0 與 M1 有相同事實。M0 不先選好下一處；按下列順序列出資料，請參與者自行判斷。每次只交付一個情境版本，不讓參與者翻到另一題。M0、M1 使用相同字體大小與相同手機／紙本媒介。

互動原型已提供 M0／M1 及 X／Y 切換。M1 S1、S2 的「所有點位資料」與 M0 使用同一份完整文字；手機可展開，紙本直接列出。S1 的 B、C 都是可用選項，選 C 並指出有效路線也算決策正確，距離另記。S3 至 S7 只做 M1，不提供 M0 切換。

主持人先選好材料，再只呈現市民告示區，遮住研究者控制，避免情境名稱洩漏線索。紙本可用瀏覽器列印，會隱藏研究者控制與按鈕並展開必要路線；每個情境、材料及地標版本各自列印。正式開始前保留固定材料副本及原型指紋，不在測試中變更文字。

## 任務記錄

每次已啟動或未開始的預排任務均留一張。下面是空白表，不是已收集資料。時間使用台北時區，秒數保留原始值；禁止把空白當零。

| 欄位 | 填寫 |
|---|---|
| 日期、研究版本、原型版本、記錄者 |  |
| 匿名參與者、熟悉度、低數位／通行需求（自願提供） |  |
| 情境、M0／M1、X／Y、紙本／手機、任務順序 |  |
| 預排／已啟動／完成／取消／退出，及原因 |  |
| 開始／首次確定答案／結束時間 |  |
| 第一個答案或實際行為，保留原意 |  |
| 原點狀態、物品與時段判斷、去處、路線各是否正確 |  |
| 提示有無、內容與發生時間 |  |
| 決策正確／錯誤／未知；安全停止有無 |  |
| 實際投放完成有無（桌面填不適用） |  |
| 原始秒數、比較用秒數，套用規則原因 |  |
| 關鍵錯誤、失敗原因、協定偏離、停止與恢復紀錄 |  |

失敗原因可複選：`status` 原點狀態、`hours` 時段、`item` 收受物、`route` 路線、`access` 通行、`full` 滿溢、`stale` 過期、`no_service` 無服務、`prompt` 需提示、`timeout` 超時、`withdrawn` 退出、`technical` 技術問題、`unknown` 未知。問題來源另標資訊錯誤、介面理解、真實服務條件或未定，不能由一次失敗直接推定根因。
