# 垃圾箱分布、撤除與設計

題目 ID：`bins`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-waste-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

已有官方清潔箱位置與歷史保存副本。獨立站比較 2015、2022、2024、2026 四份不同範圍／完整性的資料；2024 只保存第一頁，2026 為中心示範框。早期七題模型使用 294 筆框內位置，需求與候選點另為合成。

以分布、撤除歷程與桶型概念為主；歷史配置模型的服務率不是實際人口服務率，資料缺列不能直接認定撤除。

本題[資料目錄](data)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#行人專用清潔箱)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

[model.js](model.js)保存原七題版本的配置計算，供既有程式與測試相容；研究限制見[歷史模型脈絡](docs/model-research-context.md)。垃圾箱獨立站維持地圖、撤除歷程與桶型體驗，保留這份模型不代表新增選址功能。桶型尺寸與試投規則見[design-model.js](../../sites/taipei-waste-lab/dist/design-model.js)。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-waste-lab/README.md)。
