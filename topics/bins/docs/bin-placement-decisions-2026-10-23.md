# 台北行人專用清潔箱：現行決策方式補充

記錄與查證日期：2026-10-23（Asia/Taipei）。範圍為台北市街頭行人專用清潔箱的增設、保留、遷移與撤除。

本筆記保存本次對官方公開資料的查核與討論。這是研究補充，未取得個案內部簽核、現行完整評估表或現場新觀測，也不代表已採納重新配置方案。

## 公開可確認的做法

目前公開說明可整理為：市府提出配置方向，清潔隊依個別地點評估，並納入地方反映調整。這是本次資料的綜合判讀，不代表已還原所有內部行政流程。

| 決策環節 | 官方公開說明 | 來源與限制 |
| --- | --- | --- |
| 提出需求 | 民眾可透過里長或 1999 反映新設、拆除、遷移需求。 | S1；這是公開申請管道，未證明所有案件均由陳情啟動。 |
| 個案評估 | 環保局清潔隊依要件檢核撤除或遷移的妥當性。 | S1；未取得完整現行要件、評分權重與簽核分工。 |
| 設置條件 | 依實際需求考量人潮多寡及交通影響；除特殊情形外，以寬度至少 1.5 公尺的人行道為限。 | S1；該數字是公告的人行道寬度條件，不能直接當作設桶後的淨通行寬度或完整施工許可。 |
| 配置方向 | 2026 年 8 月公告以商圈、夜市、觀光景點等高人流地區為未來主要配置場域。 | S2；政策方向不等於每個地點已完成增設。 |
| 減量與撤除 | 對住宅區違規投入家戶垃圾嚴重或環境髒亂的點位，經當地里長要求，或經評估及當地里長同意後，優先減量或撤除。 | S2；全市政策理由不能直接代替每個點位的撤除理由或成效證據。 |

行人投放便利與設置地點的整潔、違規棄置治理，都是上述決策涉及的需求。里長是地方意見入口之一；現有公開資料不足以判斷地方意見、人流、清運負擔各占多少權重。

## 舊作業程序的適用界線

2021 年版《臺北市政府環境保護局行人專用清潔箱設置管理作業程序》曾明訂跨單位現勘、依評估表評估、報局核可後施作等流程。官方法規沿革確認，該程序已於 **2022-08-24 停止適用**（北市環清字第 1113054731 號函）。[S3][S4]

因此，不能直接將舊版會勘成員、表單、核准流程、施作期限或間距規則寫成現行要求。舊表單名稱仍可作為向機關詢問歷史紀錄與現行替代制度的線索。

## 尚未確認的決策依據

本次尚未找到公開、可重算的全市選址評分或排序。這表示公開證據不足，不表示政府內部必然沒有評估工具或紀錄。

| 待確認問題 | 需要補充的證據 |
| --- | --- |
| 人潮多少、行人需走多遠，才構成增設需求？ | 現行設置要件、人流與步行可及性的衡量方式、門檻及例外。 |
| 滿溢來自正常需求、容量、清運不及，還是違規投入？ | 同一點位與時段的投放、垃圾組成、容量、滿溢及實際清運紀錄。 |
| 何時增加清運、搬移或撤除？ | 各方案的比較標準、成本與服務影響，以及實際個案評估與核准紀錄。 |
| 調整後是否改善？ | 調整前後一致的整潔、行人便利與鄰近垃圾轉移紀錄；同步記錄清運與稽查變化。 |
| 現行行政流程由誰核定、使用哪些表單？ | 2022 年停止適用後的替代制度、現行表單與權責說明。 |

## 對重新佈置研究的啟示

以下是本次討論提出的研究方向，尚未成為核定配置方案：讓每個點位的增設、保留、搬移及撤除理由可以比較，並把清運調整一併納入選項。

滿溢本身不足以證明違規，也不足以直接決定撤桶。需先辨識問題，再比較位置、容量、清運與維護的可行調整。現有公告可說明政府採取調整的政策理由，尚不足以證明各次調整已兼顧便利與整潔。

本期仍聚焦行人投放、公共清潔箱配置、清運與維護。家戶垃圾違規投入在此作為既有決策背景，不新增家戶垃圾服務工作。
