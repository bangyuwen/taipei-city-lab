# 台北市行人專用清潔箱減少：研究脈絡

整理日期：2026-10-14（Asia/Taipei）。本文件保存垃圾箱減少的歷史背景、來源、推論與待驗證問題，作為垃圾箱分布與撤除歷程研究的起點。

## 問題與範圍

討論範圍為台北市街頭的「行人專用清潔箱」。先回答市府與居民為什麼要求減量或撤除，再研究撤除後對環境整潔與行人便利的影響。

以下來源支持一條長期存在的治理脈絡：家戶垃圾違規投入，造成滿溢與周邊髒亂，引起居民反對，促使市府撤除部分點位並採重點設置。這是對歷史紀錄的整理，尚未建立逐年數量序列，也未估計各項原因對全市減量的貢獻。

## 歷史與來源

| 時間 | 來源記錄的事實 | 對問題的意義 |
|---|---|---|
| 2000-07-01 | 台北市停止隨水費徵收垃圾費，改採隨袋徵收，依排出的垃圾量付費。[S1][source-1] | 家戶垃圾須使用專用垃圾袋；這是理解規避付費問題的制度背景。 |
| 2003–2004 | 主婦聯盟在2004年4月會訊中，回顧2003年與環保局合作的巡查計畫，記錄家戶垃圾投入箱內或堆在周邊，以及部分里長、住戶要求撤除的情形。[S2][source-2] | 違規棄置、居民反對與撤除要求，在早期就已出現。 |
| 2020-09-10 | 環保局說明，清潔箱優先設在商圈、觀光景點及交通場站；家戶垃圾造成滿溢，是居民反對設置的原因之一。[S3][source-3] | 配置政策偏向人流與需求集中的地點。 |
| 2026-08-10 | 環保局說明，提高裁罰及持續稽查後仍難杜絕違規；過去一年對住宅區違規嚴重或髒亂的點位，經里長要求或評估取得同意後，優先減量或撤除。[S4][source-4] | 近期撤除延續了處理違規棄置與髒亂的治理邏輯，並集中配置於高人流地區。 |

S2是參與巡查團體的當時紀錄；S3、S4是市府對政策理由的說明。它們可以支持「為何提出或採取撤除」，但不能單獨證明撤除的環境成效。

## 推論與邏輯

1. **付費制度形成重要背景。** S1建立隨袋徵收的制度事實，S2記錄部分民眾以街頭清潔箱棄置家戶垃圾、規避付費。現有來源不足以判斷每次違規者的動機或比例。
2. **違規投入帶來設置點的治理壓力。** S2、S3都記錄滿溢、髒亂及居民反對；S4進一步說明近期住宅區撤除的執行理由與程序。
3. **市府以撤除部分點位及重點配置回應。** S3、S4支持商圈、交通場站、觀光景點等高需求地點優先設置的政策方向。各點位仍需個別核對撤除、搬移或停用紀錄。
4. **滿溢也可能反映正常使用需求。** S2的巡查意見指出，部分使用率高而滿溢的清潔箱應增加清運次數。不能僅憑滿溢就推定家戶垃圾違規，或推定該撤除。

這些紀錄共同支持「違規投入 → 環境問題 → 居民反對 → 撤除或配置調整」的解釋框架。各段關係的強度，以及是否適用於某個點位，仍需現場與行政紀錄驗證。

## 待驗證假設

| 假設／問題 | 需要的證據 | 判讀時要保留的條件 |
|---|---|---|
| 家戶垃圾違規棄置是特定點位被撤除的主要原因。 | 撤除日期、點位、會勘與撤除理由、陳情及稽查紀錄。 | 新聞稿的全市政策理由不能直接當作每個點位的原因。 |
| 撤除後，當地與周邊整體髒亂減少。 | 撤除前後一致的垃圾堆置、滿溢觀測，及可比較的未撤除點位；同步記錄清運與稽查變化。 | 要觀察垃圾是否移到鄰近街道或其他清潔箱；通報數還會受到回報習慣影響。 |
| 高需求點增加清運頻率，比撤除更能兼顧整潔與便利。 | 行人需求、垃圾組成、滿溢時段、容量、清運頻率與實際工時。 | 清運調整的成效與成本需試辦觀測，不能僅用位置資料直接推算。 |
| 重點配置能維持合理的行人使用便利。 | 人行路網、不同時段的人流、尋找垃圾箱的距離與使用觀察。 | 要檢查住宅區、商圈及交通節點的需求差異；直線距離只是代理。 |

## 後續資料整理

- 單次下載與歷史保存資料的日期、範圍及完整性必須分開判讀；目錄筆數與下載列數的落差，不能當作歷史減量。
- 逐箱追蹤需要官方箱號，以及新設、搬移、撤除與復設的日期和理由。現有副本的列號不是官方箱號。
- 行人需求、垃圾量、家戶垃圾、容量、滿溢、稽查及清運負擔仍需實際觀測。歷史來源支持提出研究問題，還不能量化撤除效益或髒亂改善。
