# 清潔箱配置模型的歷史研究脈絡

原整理日期：2026-10-14（Asia/Taipei）；歸檔日期：2026-10-15。保留原研究「對現有模型的影響」一節，描述當時七題網站的清潔箱配置模型，不代表垃圾箱獨立站已納入選址模型或取得新的觀測證據。

政策背景、歷史來源、推論及待驗證假設只維護於[垃圾箱減少的研究脈絡](bin-reduction.md)，原政策來源見該文的[來源](bin-reduction.md#來源)。

## 對現有模型的影響

- [垃圾箱模型](../model.js)目前比較現有位置快照與新增候選的合成需求服務率，並納入設置數量及新增桶每日清運工時上限。這可以探索配置取捨，但尚未納入違規投入、垃圾量、容量、滿溢、稽查及實際清運路線。
- [資料查核](../../../shared/docs/data-review.md#行人專用清潔箱)記錄的是單次下載內容。目錄筆數與下載列數的落差，不能當作歷史減量；目前衍生ID也不適合直接追蹤跨版本點位。
- 後續研究需要同時考慮行人需求與維運負擔，保留新增、搬移、撤除與調整清運頻率等方案。方案比較應以同一批需求與可行條件為基準，成效再由試辦觀測驗證。
- 歷史來源支持提出研究問題，尚不足以把違規率、撤除效益或髒亂改善寫成模型中的已知參數。[既有研究對照](../../../shared/docs/research-review.md)與[深化紀錄](../../../shared/docs/deepening-review.md)保留配置方法、指標及工時假設的詳細說明。
