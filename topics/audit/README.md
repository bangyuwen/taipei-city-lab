# 市政資料健檢

題目 ID：`audit`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-data-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

來源目錄可檢視已載入與未載入狀態；使用者上傳或貼入的 CSV 由瀏覽器本機規則檢查，不上傳伺服器。沒有額外載入其他題目的實際觀測來填補缺口。

檢查欄位、缺漏、重複、日期、座標及資料契約；格式通過不代表來源真實或資料足以回答政策問題。

本題[資料目錄](data/)與[來源說明](data/catalog.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#真實資料範圍)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-data-lab/README.md)。
