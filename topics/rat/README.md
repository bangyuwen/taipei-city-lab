# 鼠患巡查與源頭治理

題目 ID：`rat`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-rat-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

尚未匯入實際鼠患通報、去重座標或現場巡查結果。Rat Radar 為未載入參考入口；陳情來源只查目錄，沒有可直接產生熱點的地址資料。情境街廓與巡查個案為合成。

安排查核線索、源頭改善與複查流程；模擬分數不是實際鼠患評級，通報多寡也不能直接當作鼠隻數。

本題[資料目錄](data)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#其餘來源已查目錄未整合觀測)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-rat-lab/README.md)。
