# 內湖錯峰通勤

題目 ID：`traffic`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-traffic-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

VD、捷運等來源目前僅核對目錄，尚未載入尖峰歷史車流、旅行時間或真實企業錯峰試辦。逐分鐘需求與瓶頸容量屬合成情境。

以固定瓶頸重算排隊與車輛延誤，保留尾段直到排隊清空；不能由合成情境宣稱實際內湖路網的減堵效果。

本題[資料目錄](data)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#其餘來源已查目錄未整合觀測)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-traffic-lab/README.md)。
