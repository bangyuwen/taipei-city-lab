# 社區健檢準備與文件查核

題目 ID：`buildings`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-building-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

建物、人口、液化及消防來源尚未載入逐棟觀測或疊合；現有來源多為彙總／目錄。示範社區、文件缺口與追蹤個案為合成。

安排健檢準備、文件補查及專業轉介；分數不是單棟耐震能力、倒塌機率或安全診斷。

本題[資料目錄](data)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#其餘來源已查目錄未整合觀測)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-building-lab/README.md)。
