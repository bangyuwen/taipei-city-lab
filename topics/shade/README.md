# 樹蔭公平

題目 ID：`shade`。這裡是本題模型、資料與研究文件的維護入口；部署程式與網站產物屬對應的 `taipei-shade-lab` 獨立站。站名與本機目錄不代表已對外部署。

## 資料與證據

樹木位置已載入：2026-10-13 下載後，中心示範框保留 39,451 筆樹木紀錄；三組重疊座標仍保留。人口權重、需求、新植候選、生長與遮蔭半徑屬情境假設。

樹點可及代理與補樹取捨；不能把位置覆蓋當作實測樹冠、熱暴露或已驗證的遮蔭公平。

本題[資料目錄](data/)與[來源說明](data/sources.json)保留實際載入狀態。資料來源、查核日及限制見[跨題資料查核](../../shared/docs/data-review.md#樹木)；本題目錄的資料說明以實際載入狀態為準，不把參考資料入口當作觀測。

## 程式與網站

本題模型只維護於[model.js](model.js)；網站建置時產生所需副本，避免在多個站分別修改演算法。對應站的啟動與建置方式見[獨立站 README](../../sites/taipei-shade-lab/README.md)。
