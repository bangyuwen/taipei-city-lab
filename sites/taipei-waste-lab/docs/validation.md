## 2026-10-15：Three.js 桶型體驗

依使用者要求新增獨立的 `#design` 入口，包含四種概念桶型、尺寸／填滿程度、視角、試投與清運操作；沒有重新加入已移除的合成需求或候選點模型。四份位置資料保持原樣。

- 13 項 Node 檢查通過，包含原資料檢查與新增尺寸正規化、桶型切換上限、截面可通過／受限、填滿停止及沿街桶深與通行空間計算。
- 靜態資產、60 個 HTML ID、下載文件、Three.js 固定版本與檔案雜湊核對通過；所有本站 JavaScript 語法檢查通過。
- 原地圖／歷程／下載桌機與手機回歸通過；本次互動回歸為避免外部服務影響而阻擋圖磚，沒有重測外部底圖可用性。
- 新增瀏覽器檢查涵蓋 1440px 桌機、390px 與320px 手機、四種設計、四個原生 range 標籤與鍵盤操作、投入口限制、試投、滿桶、清運、四個視角、返頁後單一 canvas、無水平溢出及減少動態偏好。
- 位置資料503時，3D體驗與控制可獨立使用；強制 WebGL 失敗時，仍能閱讀桶型、調整尺寸與比較數值，並提供重試。正常場景使用已安裝 Chromium 的 SwiftShader 執行 WebGL；不代表完成所有實體手機 GPU 相容性測試。
- 獨立審查抓到內桶穿越固定外殼，已改成先開蓋／門、再取桶；桌機／手機試投與清運完成目視檢查。手機執行試投與清運時，先將模型捲入可視區。

這些驗證確認程式操作、幾何比較及示意動畫，沒有驗證實際設備機構、無障礙符合性、防雨、防濫倒或清運效益。雨遮模型為後方遮罩，保留前方投放空間；模型與動畫限制見 `docs/bin-design.md`。3D資產按需載入，切換離開頁面與頁籤隱藏時停止渲染。
