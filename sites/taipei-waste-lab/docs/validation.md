- 靜態資產與下載檔案檢查通過；部署身分與靜態目錄完整，HTML ID 無重複。
- Chromium 桌機 1440×1080、手機 390×844 操作通過：四版本切換、行政區與路名搜尋、空結果提示、相同 URL 重現、CSV 下載、撤除歷程篩選及無水平溢出。

PR 審查修正：位置資料讀取失敗時，撤除歷程與導覽原本一併失效。歷程與導覽已改為獨立初始化；位置搜尋與匯出在資料未就緒時停用。Chromium 以 503 回應驗證，仍可切換歷程／來源及篩選撤除個案。

2026-10-15 清理後，網站只保留點位地圖、撤除歷程、資料與來源三個入口；移除配置實驗、合成需求與候選點、計算模組及附帶快照。四份位置 CSV 保持原有內容，2026 年來源紀錄另存為垃圾箱專用 provenance。
