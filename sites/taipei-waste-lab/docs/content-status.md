# Public content status contract

There is one current proposal: the hundred-day plan at `#plan`.
`#spec`, `#work`, and `#team` are its requirements and coordination views.
`#ideas` and `#methods` are retained aliases, not other projects.

Current work starts with a decision. Use desk evidence first. Only unresolved
evidence that can distinguish options justifies fieldwork or a comparison.
No district quota, fixed visits, mandatory A/B/C prototype or demonstration
duration is a core deliverable. Existing datasets and candidate IDs remain.

The transport overlay and candidate lists are an initial configuration reference.
They can inform provisional options for bin positions, counts and collection.
Revise those options using field evidence on access, disposal, overflow and
maintenance; retaining the current configuration is also a valid outcome.
Record the initial assumption, evidence, date, before/after configuration and
reason for each decision. Reference groups and activity peaks do not prescribe
fixed visits, bin positions or collection schedules.

Dated records keep their source content and unexecuted status. The 2026-10-17
build/operation draft, 2026-10-20 field schedule, v0.4 specification and T1
hardware exploration do not authorize current work. Place status context near
chapter headings so direct links and printouts retain that distinction.

Owners: index.html owns current narrative and integrated reading sections;
package-research.py owns archive and saved-prototype contextual rendering;
prepare-siting-overlay.py plus templates own saved map/checklist status.
Do not rewrite frozen source protocols or observations to correct presentation.

Checked public surfaces: 23 integrated panels, map/assessment standalone pages,
legacy design-thinking/PRD entries and dynamic country/design UI. Current
source facts, numerical calculations, source limitations, and unknown results
are preserved. This is a consistency check, not a new factual-source audit.

The current reading path (`#plan`, `#spec`, `#work`, `#team`) contains current
purpose, decision rules, requirements and handoffs only. The dated field plan,
v0.4 specification, old government work packages and build/budget draft are
physically in `#archive`, reached from `#library` (參考資料). Old anchors stay
valid and route to that archive. Do not reinsert those drafts as disclosures
within current panels. Current instructions must link to current requirements,
forms and handoff conditions, not to superseded draft requirements.
The archive uses document readers inside dated disclosures so multiple moved
collections and their deep links remain accessible without reader-state clashes.

The activity map at `#analysis-city-map` visualizes retained July YouBike
endpoint counts, not waste demand. `prepare-hotspots.py` derives the minimal
public payload from preserved citywide CSVs and the existing facility catalog.
No matched observation becomes null, never zero; fixed visual bins apply across
area/search filters. Campus remains a separate source category. Facility layers
retain cross-district records and do not assert access or service coverage.
The current map replaces the saved first-round-anchor figure in the main flow;
its underlying research figure and original proposal data remain preserved.
