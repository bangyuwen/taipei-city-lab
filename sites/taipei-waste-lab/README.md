# 台北垃圾箱研究

聚焦台北行人專用清潔箱的早期分布與撤除歷程。這是獨立的靜態站，資料與程式都由本站提供。

網站：[台北垃圾箱研究](https://taipei-waste-lab.bangyuwen.chatgpt.site)。GitHub 原始碼集中於 `sites/taipei-waste-lab/`；Sites 部署使用本站自己的 Git 與 `.openai/hosting.json`。

目前保留：

- 2015、2022、2024、2026 四份位置資料切換，行政區／地址搜尋、位置清單與篩選 CSV 下載。
- 有來源的撤除時間線，區分政策理由、官方存量與具日期的撤除個案。
- 各版本日期、完整性、原始來源與研究筆記下載。

## 開發與驗證

無需安裝前端依賴。Node.js 22 以上：

```sh
npm test
npm run check
npm run preview
```

已保存的 CSV、來源紀錄與前端資產均在本專案。`npm run prepare-data` 直接從本站保存檔案重建展示資料，不依賴其他專案，不會自動下載新版本或補齊歷史缺頁。

`python scripts/check-browser.py` 使用環境既有的 Playwright 與 Chromium 檢查桌機／手機、版本切換、篩選、下載與撤除歷程操作。畫面證據寫入忽略的 `qa/`。

## 結構

- `dist/`：可獨立部署的網站、固定資料、Leaflet 與字型。
- `dist/history.js`：有來源的政策與撤除歷程。
- `docs/`：討論脈絡、證據與研究限制。
- `.openai/hosting.json`：本站部署身分與靜態目錄。
