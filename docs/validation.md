# 驗證紀錄

2026-10-14，Node.js 24.19.0。

115 個自動測試通過：七個模型的預算限制與情境一致性、真實快照配置回歸、獨立枚舉的最佳配置、車流／旅客守恆與休息約束、CSV 解析、資料品質與用途判定，以及整合、修訂回歸及視角操作測試。

整合測試在模擬 DOM 中執行實際 app.js 事件處理：題目切換、參數調整、方案儲存／套用／刪除／重設、CSV 與七題匯出、檔案大小限制、CSV 不進 localStorage。也檢查損壞儲存資料、步進對齊、CSV 公式前綴防護、HTML/SVG escaping、有限座標、圖例、長條圖及檔案參照。

`npm run check` 驗證所有 JS 語法、七個模型的預設與高低參數、來源 ID、產生的 SVG／表格及同站檔案。資料準備另外驗證投影、來源列數守恆、ID、null與品質警示。

沒有執行實際瀏覽器、截圖或手機排版驗證。模擬 DOM 不代表瀏覽器渲染、下載或無障礙操作已獲人工驗收。上線成功以部署結果確認，未宣稱這些未執行的視覺檢查通過。

修訂回歸包含：延遲計算與 CSV 匯出、快速切換題目參數保留、重設取消待執行計算、健檢問題／日期保留、資料或條件變更使報告失效、請求條件追溯、台北／UTC 日曆日、未標時區字串及來源目錄狀態一致。

十輪深化增加 15 項案例：分散需求權重守恆、零年成長、獨立重算 greedy 首選、候選排除、清運工時、繞行、車輛小時、全體候車、複查／轉介狀態、組合鍵／空值／範圍契約、契約無效輸入、報告失效與參數連結重現。新增圖表亦檢查長度與有限數值。這些不是政策成效的實證驗證。

Three.js 新增 13 項測試：固定版本與檔案 SHA、經緯度投影方向／尺度、點位顯示抽樣、七題實際 Three.js 幾何／矩陣有限值、覆蓋率與原模型對應、零成長、逐分鐘交通尾段、公車休息與旅客守恆、CSV 欄位比例、各資源單次 dispose、反覆切換場景、無 WebGL 的原 UI／匯出、基準與推薦造型互斥。使用真實 Three.js 的 CPU 場景圖，不是實際 GPU 繪圖。
